### 3.2 Minimum reusable fact / provenance envelope

Prefer **one** reusable minimal mechanism (new thin helper under CB-02 or adjacent) that can attach to:

- canonical property facts;
- Decision-facing fact refs / package slices;
- derived facts (derivation/input lineage);

without inventing a national provenance platform or full temporal history ledger.

Envelope must be able to carry (where applicable, null-honest when absent):

| Field class | Intent |
|-------------|--------|
| source identity | organism / family / SourceRef id |
| jurisdiction | from PS05-02 when known |
| source/raw record reference | rawIdentifiers / payload refs |
| acquiredAt | SourceRef / pack |
| vintage / effective / recorded | when available |
| transform / derivation reference | for DERIVED |
| trust state | PS05-01 markers |
| conflict state | OPEN / RESOLVED / none |
| freshness state | CURRENT / STALE / UNKNOWN_FRESHNESS |
| factType | M10 enum |

### 3.3 Fact typing (minimum enum class)

Bounded enum (names may be normalized by Pre-IMPL to existing vocabulary):

```text
OBSERVED | DERIVED | ESTIMATED | UNKNOWN | CONFLICTING | STALE | SYNTHETIC | STUB
```

Rules:

- SYNTHETIC / STUB remain **non-Decision-trusted** (PS05-01).
- UNKNOWN / CONFLICTING / STALE are honest states — not invent values.
- No AI-authored authoritative OBSERVED facts.

### 3.4 Dynamic unknown semantics

Unknowns MUST be derived from:

1. minimum Decision-relevant expected fact classes for current Factory handoff; and/or
2. source-class outcomes (FAILED / UNAVAILABLE / NOT_CHECKED / PROHIBITED / STALE);

**not** from inventing Obl entries to satisfy G5.

`buildDefaultKnownUnknowns` hardcoded Obl path is a **confirmed deficit** to remediate under M11.

Do **not** attempt exhaustive nationwide fact inventory.

### 3.5 Source exhaustion semantics (minimum)

Machine-readable states for Decision-relevant source classes:

```text
EXPECTED | CHECKED | NOT_CHECKED | FAILED | UNAVAILABLE | PROHIBITED | STALE
```

Honest bounded completeness only. Do not claim jurisdiction-wide source universe exhaustion. DST motivation “exhausted” ≠ source exhaustion.

### 3.6 Fact exhaustion semantics (minimum)

Decision-facing fact status:

```text
FOUND | UNKNOWN | UNAVAILABLE | CONFLICTING | STALE | DERIVED | ESTIMATED
```

Minimum Decision-relevant expected fact classes only (identity/jurisdiction/owner-ref honesty/provenance/trust/conflict/freshness slices as frozen by Pre-IMPL). Not Deal Dossier / full DDI.

### 3.7 Conflict semantics

If two credible sources disagree:

- **A.** conflict survives explicitly downstream; **or**
- **B.** explicit authority rule resolves with retained provenance.

Reuse R1–R8 / MotEvd02 / `assertNoAveraging`. Silent overwrite / averaging is forbidden. CB-16 must gain a Decision-facing conflict slice or equivalent hook (not rely solely on opaque ELR dump).

### 3.8 Freshness semantics

Reuse `evaluateFreshness` + SourceRef `vintageAt` / `acquiredAt` / `freshness` blob.

Decision-facing distinction minimum:

```text
CURRENT | STALE | UNKNOWN_FRESHNESS
```

Unknown freshness must **not** be treated as current. Pack/FRS UNAVAILABLE behavior from PS05-01 must remain. No SP07 monitoring.
