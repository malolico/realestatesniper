## 10. Append-only / non-destructive semantics (frozen)

Semantic model only. **NOT** a storage engine.

```text
newer record does not overwrite older record
older historical truth remains present
correction/supersession creates a later record
prior record remains explainable
history must not be silently rewritten
historical negative / UNKNOWN / CONFLICT evidence remains historically visible
```

This Freeze **does not** authorize filesystems, databases, event stores, or object storage.

---

## 11. Correction / supersession (frozen)

```text
correction / supersession
  = new historical record + explicit lineage
  ≠ mutation / deletion / replacement of the prior historical record
```

A newer record MAY represent a newer **active** truth posture while preserving the earlier historical fact **exactly as recorded**.

`supersession.supersedes` cites the prior archive-record identity. The prior record **remains in sequence**.

## 15. Ordering (frozen)

Deterministic ordering sufficient for reproducible history.

**Primary:** lineage — a record whose `lineageRefs` cite another archived source MUST sort after that cited predecessor when both are in the same sequence.

**Secondary:** canonical recorded time from `canonicalTime` fields that are **present** (P1 `evaluatedAt` / snapshot `observedAt` via `inputRef`; P2 `predecessorRef.evaluatedAt` / `candidateRef.observedAt`).

**Tie-break (when times equal or both null):**

1. `sourceArtifact.kind` order: `WATCH_RESULT` before `UPDATE_RESULT`
2. lexicographic `sourceArtifact.schemaId`
3. JSON-canonical identity of `lineageRefs`
4. lexicographic source `ruleVersion`

**Forbidden ordering sources:**

```text
Date.now()
random
environment-dependent keys
mutable global counters
runtime "archive now"
```

Missing timestamps **MUST NOT** be invented. Absence participates in tie-break, not in silent time fabrication.
