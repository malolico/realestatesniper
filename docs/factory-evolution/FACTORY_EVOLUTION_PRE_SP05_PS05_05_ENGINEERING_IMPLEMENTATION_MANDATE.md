## 1. Purpose

Establish a **Trusted CB-16 boundary** so that Factory Decision Packages intended for future Decision Engine consumption are either:

1. **Decision-trusted** under PS05-01 contamination rules + honesty fields; **or**
2. **Explicitly refused / hard-marked non-consumable** on the trusted consumption / handoff / export path;

and bind **readiness ≠ opportunity** (and ≠ investment recommendation / quality synonym) so construction readiness and package readiness facts cannot be read as deal classification, ranking, Premium/Diamond, or investment advice.
